# UXPRESSO PRD v3.1 — `mega-ver.2` 구현 기준

> 메가MGC커피 셀프오더 키오스크 UX/UI 개선 **비공식** 프로토타입.
> 이 문서는 [PRD v3.0](prd-v3.0.md)(팀 원문)을 바탕으로 **지금 실제로 만들어진 것**과 팀 요청으로 바뀐 결정을 정리한다.
> 배경·사용자·JTBD·문제 가설은 v3.0 00~06장을 그대로 따른다. 개선 효과는 검증 전 가설이다.

- 기준일: 2026-11-26
- 브랜치: `mega-ver.2`
- 화면: 1080 × 1920 세로, 한국어
- 화면 규칙: [디자인 시스템 v7.1](design-system/uxpresso-design-system-v7.md) · [v2.1 적용 결과](refinement-v2.1.md)

## 1. 목표

누구나 쉽게, 혼자서도 자신 있게. 디지털 기기가 익숙하지 않은 고객이 도움 없이 메뉴를 찾고 정확히 주문한다. 터치만으로 전체 주문이 가능하고, 음성은 선택 기능이다.

## 2. 사용자 흐름

```
시작(매장/포장) → 메뉴 → 상품 화면(온도·옵션·수량) → 장바구니 → 주문 확인
   → 할인·적립 / 결제 수단 → 결제 안내 → 결제 확인 → 주문 완료 → (30초 뒤) 시작
```

- 상품과 결제 수단은 누르면 바로 다음 화면으로 간다.
- 음성 주문은 시작·메뉴·상품 화면에서 켠다. 주문 확인부터는 마이크를 끄고 버튼도 숨긴다.
- 도움말·오류·뒤로가기 후에도 장바구니는 유지한다. 장바구니가 바뀌면 쿠폰은 다시 적용해야 한다.

## 3. 화면별 요구사항

### 3.1 시작
- 상단 광고 자리(공식 그래픽 없음, 자리 표시), 매장에서 먹기 / 포장하기, 음성으로 주문하기, 언어, 도움말, 비공식 고지.
- 언어는 한국어만 동작한다. English·日本語·中文은 "준비 중".

### 3.2 메뉴
- 상단: 처음으로(담은 메뉴가 있으면 확인 대화상자), 로고 자리, 주문 방식, 도움말, 음성으로 주문하기.
- 카테고리 8개 한 줄(옆으로 밀기): 신메뉴 · 추천메뉴 · 커피 · 디카페인 · 음료 · 티 · 푸드 · 상품. 첫 화면은 추천메뉴.
- 추천메뉴: BEST 4종 뒤에 신메뉴 6종.
- 하위 분류: 음료(라떼·음료 / 에이드·주스 / 스무디·프라페), 푸드(베이커리 / 디저트 / 샌드위치·간식), 상품(굿즈 / 콜라보 상품). 온도 필터는 없다.
- 상품 3열 세로 롱 스크롤 + 아래 별도 줄의 위로 보기 / 아래로 보기. 상품에서 돌아오면 보던 위치 유지.
- 카드: 사진, 상품명, 가격, NEW·BEST·품절 배지.
- 하단: 장바구니 개수, "○○ 외 N종", 전체 삭제(확인), 주문금액, 주문 확인. 그 아래 별도 영역에 시간 연장.

### 3.3 상품 화면
- 사진, 이름, 설명(3줄), 가격, 가격 오른쪽의 **자세히 보기**(설명·용량·열량·알레르기·영양).
- 온도: 두 가지면 "어떤 온도로 드시겠어요?" 필수 선택(HOT 따뜻하게 / ICE 차갑게). 한 가지면 선택 없이 "ICE · 차갑게"처럼 표시한다. 온도가 없는 상품은 표시하지 않는다.
- 옵션(선택, 추가 금액 표시): 샷, 시럽, 얼음 양(ICE만), 휘핑크림. 상품에 따라 다르다.
- 수량 1~20, 선택 금액 실시간 표시, 장바구니에 담기. 필수 온도를 고르기 전에는 비활성 + 이유 안내.

### 3.4 주문 확인
- 상품 이미지, 이름, 온도, 추가 옵션과 금액, 수량. 수량 변경, 옵션 변경, 삭제(확인), 메뉴 더 담기, 할인·결제하기.

### 3.5 할인·적립·결제
- 금액 요약(주문 방식·개수·쿠폰 할인). 제목은 `주문금액`, 쿠폰 적용 후에는 `최종 결제금액`.
- 할인·적립 8개: KT 멤버십, T멤버십, SKT 우주패스, CJ ONE, 기아멤버스, 현대 M포인트, 메가 쿠폰, 스탬프 적립.
- 결제 15개: 신용·체크카드/삼성페이 1, 휴대폰 결제 11, 상품권·선불카드 3(모바일 상품권, 메가선불페이, CJ기프트카드). 현금은 안내 문장만.
- 선택지 23개(v3.0이 말한 22개 타일 + 이 시안의 구성)가 한 화면에 모두 보인다. 직원 도움 버튼.
- 멤버십 할인은 모의 안내만 한다. 쿠폰은 서버가 계산한다. 스탬프 번호는 저장하지 않는다.
- 쿠폰으로 전액 결제되면 결제 수단 없이 완료한다.

### 3.6 결제·완료
- 결제 수단별 안내 → 결제하기 → 처리 중. 중복 요청을 막는다.
- 실패: 원인과 해결 방법, 다시 결제 또는 다른 수단. 확인 중·결과 불명: 다시 결제하지 말라고 안내.
- 승인되면 주문 번호, 주문한 상품·수량·온도, 주문 방식, 금액, 픽업 안내. 30초 뒤 처음으로.

### 3.7 음성 (모의 입력)
- 준비된 발화 버튼으로 시연한다. 실제 음성 인식은 없다.
- 지원: 분류 이동, 상품 선택(온도·수량), 온도·수량 변경("따뜻한", "차가운 걸로 바꿔줘"), 담기, 선택 마치기.
- 담기 전에 상품·온도·수량·옵션·금액을 확인 줄로 보여 준다. 터치와 같은 선택 상태를 쓴다.
- 결제·쿠폰·적립 발화는 실행하지 않고 직접 누르라고 안내한다. 주문 방식은 대신 고르지 않는다.
- 안내는 항상 화면에 표시하고, 소리 안내는 켤 때만 낸다.

### 3.8 세션
- 120초 미조작 → 안내 대화상자(60초 카운트다운) → 초기화. 계속 주문하기를 누르면 장바구니 유지.
- 시작·완료 화면, 결제 처리 중, 음성 처리 중에는 초기화하지 않는다.
- 시간 값은 가설이며 운영 정책으로 검증해야 한다.

## 6. 팀 확인이 필요한 것

1. **접근성 기능 제거** — v3.0의 P0 "기본 접근성"·FR-19, 주요 대상 사용자와 맞는지.
2. **목록의 온도 정보 제거** — FR-03과 다름.
3. **BEST 지정** — 시연용이다. 발표에서 인기 순위로 설명하지 않는다.
4. **공개 저장소** — 홈페이지의 설명·영양 문구가 누구에게나 보인다.
5. **브랜드 로고** — 사용 허락과 공식 파일이 필요하다.
6. 맨 위의 `MEGA_UXPRESSO_Design_System_v6.md`는 `docs/design-system/`의 v6과 같은 파일이다(팀원 업로드).
