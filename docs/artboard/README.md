# Claude Design 아트보드 백업

claude.ai Design 캔버스 "UXPRESSO 키오스크 아트보드"의 소스 백업입니다. 원본(편집·공유)은 캔버스 링크에 있고, 이 폴더는 보관용 사본입니다.

- 캔버스: https://claude.ai/artifact/D4HRhRsDASBuHYcqLfepeZ (비공개, 공유 설정은 페이지의 Share 메뉴에서)
- 백업 시점: Design System v2 적용 버전
- `canvas.json` 아트보드 배치·메모 / `kiosk.css` 공통 스타일 / `*.dc.html` 화면 12장 (1080×1920, 정적 시안)
- `*.dc.html`은 캔버스 전용 포맷(`support.js` 필요)이라 브라우저에서 단독으로 열면 제대로 보이지 않습니다. 캔버스에서 보세요.
