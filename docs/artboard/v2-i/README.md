# v2-I 키오스크 프로토타입 시안 (Claude Design 보드)

claude.ai Design 캔버스의 **v2-I** 보드(1080 × 1920) 소스 백업입니다. v2-B(프로모션 첫 화면 + 원형 오비트 메인)를 고쳐 온 v2-D~H를 이어서 만든 최신 버전입니다. 비공식 시안이며 메가MGC커피의 공식 자료가 아닙니다.

- 캔버스(비공개, 공유는 페이지의 Share 메뉴): https://claude.ai/artifact/5Tj92u2BFCmAkBLzzg2shL  — 보드 이름 `v2-I · v2-H 수정안`
- `PopOrbitI.dc.html`은 캔버스 전용 포맷이라 단독으로 열면 이미지가 보이지 않습니다(캔버스에서 보세요). 브라우저에서 바로 보려면 아래 두 가지를 쓰세요.

## 바로 열어 보기
| 용도 | 열 파일 | 설명 |
|---|---|---|
| **클릭해 보는 프로토타입** | `prototype/index.html` | 더블클릭하면 크롬 등에서 열립니다. 프로모션 → 메인 → 메뉴 → 상세 → 주문서 → 결제 → 완료와 음성 모의 입력이 동작합니다. `support.js`는 캔버스 런타임(React 포함)이라 같은 폴더에 두어야 합니다. |
| **Figma에 가져오기용 화면** | `html/all-screens.html`, `html/screens/*.html` | 동작 없는 정지 화면 35장(1080 × 1920)을 일반 HTML/CSS로 만든 것입니다. HTML을 Figma로 바꿔 주는 플러그인(예: html.to.design)으로 가져와 수정하세요. 한 장씩은 `html/index.html`의 목록에서 엽니다. |

- 두 곳 모두 **인터넷이 필요**합니다. 메뉴 이미지는 `docs/menu-image-links`의 주소에서, 글꼴(Pretendard·Black Han Sans·Noto Sans KR)은 CDN에서 불러옵니다. 흰 배경은 열 때 브라우저에서 지웁니다(실패하면 흰 배경이 보일 수 있음).
- 프로모션 포스터(팀이 준 이미지)는 `prototype/assets/poster.webp`에 있고, 첫 화면과 `html/` 화면에서 이 파일을 불러옵니다. 다른 포스터로 바꾸려면 같은 이름으로 교체하세요.
- Figma 가져오기는 플러그인마다 방식이 달라 직접 확인하지 못했습니다. 로컬 파일이 안 열리면 HTML을 웹에 올린 주소로 가져오세요.

## 화면 흐름
프로모션(포스터 + 자동 슬라이드, 터치하면 시작) → 메인(돌아가는 8개 메뉴, 음성으로 주문하기) → 메뉴(카테고리·서브메뉴·3열) → 상세·옵션(HOT/ICE, 샷, 수량) → 주문서(매장에서 먹기/포장하기 선택) → 할인·결제 → 결제 처리 → 완료(영수증 발행/미발행)

이번 버전에서 바뀐 점: 커피 서브메뉴는 에스프레소·라떼·콜드브루만, 완료 화면의 영수증 버튼을 아래로 내림, 메뉴 이미지·상품을 `docs/menu-image-links` 목록 237개 기준으로 전부 채움, 글꼴은 타이틀만 Black Han Sans·나머지 Pretendard.

## 파일
| 파일 | 설명 |
|---|---|
| `PopOrbitI.dc.html` | 보드 소스 (프로모션~완료 전 화면, 음성 모의 입력 포함) |
| `menu-data.json` | 메뉴 192개(HOT/ICE는 한 상품으로 합침) — 카테고리·서브메뉴 태그·배지·온도·예시 가격·이미지 파일명 |
| `prototype/index.html`, `prototype/support.js` | 클릭해 보는 단독 실행 프로토타입(위 표 참고) |
| `html/` | Figma 가져오기용 정지 화면 HTML 35장 + 전체 화면 한 페이지 |
| `tools/build_menu_data.py` | `docs/menu-image-links` 목록 → `menu-data.json` 생성 (분류 규칙은 이 파일에 있음) |
| `tools/build_sprites.py` | 이미지를 내려받아 흰 배경을 지우고 8×8 스프라이트 시트 4장으로 묶음 (결과는 `build/`, 저장소에 올리지 않음) |

## 알아둘 점
- **이미지는 저장소에 올리지 않았습니다.** `docs/menu-image-links/README.md`의 안내대로 시안 작업에만 쓰기 때문입니다. 필요하면 `tools/build_sprites.py`로 다시 만드세요.
- **가격은 시연용 예시**이고, 카테고리·서브메뉴는 메뉴 이름으로 나눈 시안용 분류입니다. 실제 메뉴 정책이 아닙니다.
- 신메뉴는 포스터에서 NEW로 확인된 5개와 콜라보 2개만 넣었고, 추천메뉴 12개는 시안용으로 직접 고른 것입니다(인기 순위 아님).
- 결제 수단 타일의 동그라미 로고는 이름 첫 글자 자리 표시입니다(공식 로고 파일 없음).
- 음성 주문은 마이크 대신 모의 입력 칩으로 시연합니다.
