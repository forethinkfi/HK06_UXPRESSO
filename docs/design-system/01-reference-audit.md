# 01. Reference Audit — 메가MGC커피 모바일 앱 UI

출처: 유아이볼 「메가MCG커피」 iPhone 스크린샷 (열람 2026-11-25). 일부 화면만 열람 가능했습니다([README](README.md#레퍼런스-출처와-한계) 참고). 값은 화면에서 읽은 **[추정]** 이며 공식 값이 아닙니다.

## 확인한 화면 (근거)

| 화면 | 관찰 내용 |
|---|---|
| 앱 소개 이미지 | 노란 배경의 둥근 사각 앱 아이콘에 검정 "MGC" 컵 마크. 노란 배경 위 검정 굵은 헤드라인. 홈 상단은 노란 영역 + 일러스트 |
| 메가오더 상품 목록 (PLP) | 흰 배경. 상단 텍스트 탭(선택: 굵은 검정 + 밑줄). 필터 칩(선택: 검정 채움 + 흰 글씨 / 비선택: 연회색 채움). "총 17건"(숫자만 파랑). 목록 행: 좌측 둥근 정사각 이미지(연회색 배경), 우측 메뉴명(굵게)·가격(굵게). 노란 NEW 깃발 배지, 파란 SALE 배지, 취소선 정가. `ICE` 는 작은 파란 글씨. 하단: 검정 바 "매장을 선택해 주세요 >" + 노란 가방 아이콘(수량 배지) + 5탭 내비게이션 |
| 결제 설정 | 중앙 제목 + 좌측 뒤로가기 chevron. 회색 섹션 라벨, 구분선, 우측 chevron 행. 라디오: 선택 시 노란 채움(안쪽 흰 점), 비선택은 회색 테두리 |
| 결제수단 관리 | 연한 노랑(크림) 안내 카드 + 노란 원형 + 아이콘. 하단 고정 흰색 버튼(얇은 테두리, 작은 모서리) |
| 카드 등록 | 중앙 제목 + 우측 ✕. 회색 채움 입력창(테두리 없음). 통신사 세그먼트: 선택 시 검정 채움 + 흰 글씨. 약관 동의: 노란 체크 원. 하단 전폭 CTA: 연한 노랑 + 회색 글씨(비활성 상태로 보임) |
| 결제 비밀번호 입력 (오류) | 큰 굵은 안내 문구, 빨간 느낌표 아이콘 + 빨간 한 줄 오류 문구(원인 안내), 큰 숫자 키패드(회색 숫자, 배경 없음) |

## 분류 기준

- **INHERIT** 앱에서 그대로 계승 · **ADAPT** 키오스크에 맞게 조정 · **CREATE** 키오스크 전용 신규 설계

| Language & accessibility controls | 해당 없음 | 헤더에 언어·접근성 컨트롤 영역 | **CREATE** | 외국인·고령층·신체 제약 고객 |

## 확인 필요 항목 (임의로 추측하지 않음)

- 공식 브랜드 컬러 hex, 서체 이름, 정확한 px 규격
- 옵션 선택·장바구니·쿠폰·주문 완료 화면의 앱 UI
- HOT 표기의 색상, 품절·준비 중 상태 UI
- 실제 키오스크의 해상도·물리 크기·설치 높이, 결제 단말기/스캐너 위치
- 공식 로고 자산 사용 가능 여부
