# MEGA MGC COFFEE Kiosk Design System — UXPRESSO v7.0

> `mega-ver.2` 화면에 실제로 적용된 규칙. [v6.0](uxpresso-design-system-v6.md)(팀 원본)에 이후 팀 요청을 합친 **현재 기준**이다.
> 비공식 제안이며 실제 키오스크 검증 전이다. 값은 [`public/tokens.css`](../../public/tokens.css)와 [`public/style.css`](../../public/style.css)가 기준이다.

- 기준일: 2026-11-26
- 캔버스: 1080 × 1920, 좌우 여백 40, 콘텐츠 폭 1000

## 1. 원칙
1. 브랜드는 유지한다. 로고·상품 사진·결제 브랜드를 임의로 만들거나 바꾸지 않는다.
2. 같은 행동은 같은 모양으로 표현한다.
3. 선택 상태를 굵은 테두리로 강조하지 않는다.
4. 상품이 인터페이스보다 먼저 보인다.
5. 확인되지 않은 정보(인기, 영양, 알레르기)는 지어내지 않는다.

## 4. 모양
| Radius | 값 | 용도 |
|---|---:|---|
| xs | 4 | 배지, 라벨, 로고 자리 |
| sm | 8 | 버튼, 탭, 옵션, 타일, 입력, 키패드 |
| md | 12 | 상품 타일, 대화상자, 음성 안내, 결제 요약 |
| full | 999 | 라디오, 단계 표시 |

- 테두리는 모든 상태에서 1px(안쪽 그림자로 그려 레이아웃이 움직이지 않음).
- 그림자는 대화상자에만(`0 8px 24px`).
- 아이콘: Lucide 0.460, 2px, 기본 32(결제 카드 64, 완료 96).

## 5. 상태
| 상태 | 배경 | 테두리 | 글자 |
|---|---|---|---|
| Default | 흰색 | #949494 | #171717 · 500 |
| Selected (옵션) | 흰색 | #171717 | 600 + 라디오 |
| Selected (탭) | #FFDC00 | 없음 | #171717 · 700 |
| Pressed | #F2F2F2 (Primary는 #E7BE0B) | #171717 | — |
| Disabled | #F5F5F5 | #D9D9D9 | #767676 |
| Focus Visible | — | 링 2px, offset 3px, #171717 | — |

- 눌림은 터치하는 순간만. 터치 후 포커스 링은 남기지 않는다.
- 키보드로 고른 뒤에는 같은 버튼에 포커스를 돌려놓는다.
- 상품 카드와 결제 타일에는 지속 선택이 없다.

## 6. 컴포넌트

### 6.1 버튼
| 종류 | 높이 | 모양 | 사용 |
|---|---:|---|---|
| Primary | 112 | 노랑, 테두리 없음 | 주문을 진행하는 행동만, 영역당 하나 |
| Secondary | 88 | 흰색 + #949494 | 이전, 닫기, 옵션 변경, 직원 도움 |
| Destructive | 88 | Secondary + 빨간 글자 | 삭제, 전체 삭제(확인 필수) |
| Tertiary | 80 | 배경 없음 | 처음으로, 시간 연장 |
| Voice | 88 | 검정 | 음성으로 주문하기 |
| Icon | 80×80 | `aria-label` 필수 | 수량, 도움말, 위·아래 |

대화상자의 "닫기"는 Secondary다.

### 6.2 헤더
높이 112, 하단 옅은 선. 처음으로/이전 · 로고 자리(136×56) · 주문 방식 · 도움말 · 음성.

### 6.3 카테고리·하위 분류
- 카테고리: 224×88, 간격 8, 한 줄 가로 스와이프. 다섯 번째가 반쯤 잘려 더 있음을 알린다. 선택한 탭은 화면 안에 맞춘다.
- 하위 분류: 높이 80, 좌우 32.
- 선택 표시는 노랑 채움(체크 없음).

### 6.4 상품 목록·카드
- 3열, 열 간격 24, 행 간격 48, 세로 스크롤. 분류를 바꾸면 맨 위, 같은 분류에서 다시 그릴 때는 위치 유지.
- 카드: #F5F5F5 타일(1:1, Radius 12, 사진 안쪽 16, 흰 배경은 multiply로 제거) → 16 → 상품명(최대 2줄) → 8 → 가격. 왼쪽 정렬.
- 카드에 온도 표기와 상세 버튼은 없다. 누르면 상품 화면.
- 사진이 없으면 "사진 준비 중".
- 위·아래 버튼: 우측 하단 24, 세로 간격 16, 80×80. 화면의 80% 이동, 끝에서 비활성, 스크롤할 것이 없으면 숨김. 마지막 줄이 가리지 않게 아래 여백 208.

### 6.5 배지 (썸네일 좌측 상단)
| 배지 | 색 | 조건 |
|---|---|---|
| NEW | #171717 배경 + #FFDC00 글자 | 홈페이지 신메뉴 |
| BEST | #FFDC00 배경 + #171717 글자 | 데이터 `best: true` (현재 시연용 4종) |
| 품절 | #171717 배경 + 흰 글자 | `available: false` (다른 배지 대신, 주문 불가) |

배지가 있으면 사진을 56 내려 원본 이미지의 스티커와 겹치지 않게 한다.

### 6.6 상품 화면
- 상단: 사진 320 + 이름, 설명 3줄, 가격, "상세 정보 펼치기/접기"(Secondary).
- 상세 패널: 설명, 온도별 용량·열량·알레르기·영양(3열), 확인 안내와 기준일.
- 섹션: 제목 + `필수`/`선택` 라벨 + 선택지. 제목 아래 설명 문구는 두지 않는다.
- 온도: 글자만("HOT 따뜻하게", "ICE 차갑게"), 아이콘 없음, 높이 112.
- 단일 온도: 라벨 "HOT 전용"/"ICE 전용" + 연회색 고정 상자("ICE만 주문할 수 있어요"). 버튼이 아니며 비활성 선택지를 두지 않는다.
- 옵션: 2열, 최소 96, 라디오 32(선택 시 검정 원 + 노랑 점), 추가 금액은 오른쪽.
- 수량: 80×80 − / +, 값 폭 72.

### 6.7 하단 영역
- 장바구니: 상단 1px. 요약(최근 메뉴 + 시간 안내) · 시간 연장 · 전체 삭제 / 총 금액 / 주문 확인(112).
- 결정 영역: Secondary 320 + Primary, 높이 112.

### 6.8 결제
- 금액 요약: #F5F5F5, Radius 12.
- 순서: 할인·적립 → 카드 → 휴대폰 → 상품권. 제목에 아이콘, 섹션 간격 32.
- 타일: 4열(상품권 3열), 최소 128, 로고 자리 + 이름 + (보조 설명).
- 카드 타일: 전체 폭 160, 아이콘 64, 오른쪽 화살표.
- 로고 자리: 높이 40, 폭 96~160, contain. **공식 파일만** 넣고 색·비율을 바꾸지 않는다([방법](../../public/logos/README.md)).
- 쓸 수 없는 수단은 문장으로 안내한다.

### 6.9 단계 표시
메뉴 선택 · 주문 확인 · 할인·결제 · 주문 완료. 완료 = 검정 원 + 체크, 현재 = 노랑 원 + `aria-current`, 예정 = 회색.

### 6.10 음성 안내
켰을 때만 표시. 상태, 말한 내용, 응답, 다음 행동, 음성 안내 ON/OFF, 음성 종료, 연습 발화(한 줄 가로 스크롤). 챗봇·말풍선·과한 애니메이션 금지.

### 6.11 대화상자·피드백·세션
- 대화상자는 겹치지 않는다. Padding 40, 간격 24.
- 피드백: 아이콘 + 원인 + 해결 방법. 색만으로 알리지 않는다.
- 숫자 키패드: 3열, 키 96, 전체 지우기·한 글자 지우기.
- 세션 안내에만 남은 초를 보여 준다.

## 7. 콘텐츠
- 쉬운 해요체. 행동과 결과가 보이는 버튼 문구.
- 재촉·실수 지적 표현, 대기 인원 표시 금지.
- 금액 `1,100원`, 주문 번호 `A-127`.
- "비공식" 고지를 유지한다.

## 8. 접근성
- 일반 터치 80 이상, 키·옵션 96 이상, 주요 버튼 112 이상.
- 글자 대비 4.5:1, 상태 표시·기본 테두리 3:1.
- 음성 없이 주문할 수 있고, 소리 없이 음성 주문을 이어갈 수 있다.
- 키보드 포커스, 화면 전환 시 제목으로 이동, `prefers-reduced-motion` 존중.
- 접근성 메뉴, 고대비 모드, 화면 확대는 **제공하지 않는다**(팀 요청). PRD v3.0과 차이가 있어 확인이 필요하다.
