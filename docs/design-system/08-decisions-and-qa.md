# 08. Design Decision Log · Validation · QA

> 개선 효과는 아직 검증되지 않은 **가설**입니다. 실제 사용성 테스트 전에는 확정적인 성과로 표현하지 않습니다.

## 프로토타입 적용 현황 (1차 → 2차)

`public/`의 프로토타입에 2차 토큰을 적용했습니다(`public/style.css`의 `:root`와 v5 블록, `app.js`의 온도 라벨).

| 항목 | 1차 (이전) | 2차 (현재 프로토타입) | 상태 |
|---|---|---|---|
| Primary 버튼 | 주황 `#FF9F1A` | 브랜드 노랑 `#FFDC00` + 검정 글씨 | 적용 |
| 진한 색 | 진갈색 `#33190A` | 브랜드 검정 `#171717` | 적용 |
| 가격 텍스트 | 진한 주황 | 검정 Bold | 적용 |
| 선택 카드 | 검정 채움 + 흰 글씨 | 3px 검정 테두리 + 연노랑 면 + ✓ (칩·탭은 검정 채움 유지) | 적용 |
| 기본 테두리 | 검정 | `#767676` 2px | 적용 |
| 온도 라벨 | `따뜻하게 (HOT)` | `HOT 따뜻하게` | 적용 |
| 모서리 | 28px | 버튼 16 / 카드 12 / 모달 24 | 적용 |
| 서체 | 시스템 | Pretendard 우선(미탑재 시 시스템 서체로 대체) | 부분 — 서체 파일 미포함 |
| 타이포 스케일 | 본문 32px 기본 | **미적용** — 더 큰 현재 크기를 유지. 22px 스케일은 실기기 검증 후 결정 | 보류 |
| Progress 단계 표시 | 없음 | **미구현** | 미적용 |
| 언어·접근성 컨트롤 영역 | 없음 | **미구현** | 미적용 |
| 세션 미사용 확인 대화상자 | 완료 후 자동 복귀만 | **미구현** | 미적용 |

아직 적용하지 않은 항목은 시스템 문서가 명세이고 프로토타입에는 반영되어 있지 않습니다. Claude Design 아트보드와 `docs/design-system.md`(1차)는 갱신하지 않았습니다.

## 검증 지표 (Primary KPI: 독립 주문 완료율)

외부 사람의 도움 없이 과업 조건에 맞는 주문을 정확하게 완료한 시도의 비율. 키오스크 내부 도움 기능 사용은 허용.
보조 지표: 최초 선택 정확도 · 메뉴 탐색 성공률 · 옵션 선택 오류 횟수 · 오터치 횟수 · 주문 수정 성공률 · 결제 수단 선택 정확도 · 오류 복구 성공률 · 외부 도움 요청 횟수 · 주문 난이도 · 주문 자신감 · 주문 소요 시간.
검증 과업: 가져갈 음료 주문 · 원하는 특징의 음료 찾기 · HOT/ICE 및 추가 옵션 · 잘못 고른 메뉴 수정 · 사용할 수 없는 테스트 쿠폰 확인 · 지정 결제 수단 선택 · 결제 실패 후 다른 방법으로 주문. 기존 키오스크와 비교하고, **기존 고객의 사용성이 저하되지 않았는지**도 검증합니다.

## QA Checklist

| 영역 | 항목 | 상태 |
|---|---|---|
| 시각적 일관성 | 모든 화면이 같은 토큰·인스턴스 사용, 화면별 새 스타일 없음 | ☐ |
| 컴포넌트 재사용성 | Variants·Properties로 상태 표현, 중복 컴포넌트 없음 | ☐ |
| 텍스트 가독성 | 핵심 정보 ≥ 24px, Caption에 핵심 정보 없음, 실제 시청 거리 확인 | ☐ (실기기) |
| 명도 대비 | 텍스트 4.5:1 / 큰 텍스트·UI 3:1 (02-foundations 표 + 실제 화면 재측정) | ☑ 토큰 계산 / ☐ 화면 측정 |
| 터치 조작성 | 터치 영역 ≥ 88px, 간격 ≥ 16px, 15~20mm 환산 확인 | ☐ (실기기) |
| 선택 상태 인지 | 색 + ✓ + 테두리 + 문구 | ☐ |
| 오류 복구 | 모든 오류가 원인 + 해결 + 주문 유지, 재결제 금지 규칙 | ☐ |
| 다국어 대응 | 언어 변경 시 주문 유지, 길이 변화·줄바꿈 | ☐ |
| 세션 관리 | 미사용 확인, 결제 중 초기화 제한, 완료 후 초기화 | ☐ |
| UX Writing | 모호한 버튼 없음, 재촉·탓하는 표현 없음 | ☐ |

### 실제 기기 검증 필요 항목

해상도·물리 크기·설치 높이 · 시청 거리별 가독성 · 터치 센서 정확도(장갑·손톱·젖은 손) · 카드 단말기·스캐너 위치와 안내 방향 · 휠체어 도달 범위 · 주변 조도에서의 대비 · 무인정보단말기 접근성 법령·표준 충족 여부 · 공식 브랜드 컬러·서체·로고 사용 권한 · 실제 쿠폰·결제 정책.
