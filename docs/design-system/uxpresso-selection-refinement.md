# UXPRESSO Design System — 현재 적용 규칙 (v6 개선)

> `mega-ver.2` 화면에 **실제로 적용된** 개선 규칙이다. [v6](uxpresso-design-system-v6.md)과 다른 항목은 이 문서를 우선하고, 여기에 없는 항목은 v6을 따른다.
> 팀 요청을 차례로 반영해 정리했다(2026-11-26). 비공식 제안이며 실제 키오스크 검증 전이다. 토큰은 `public/tokens.css`가 기준이다.

## 1. v6과 달라진 점
| 항목 | v6 | 현재 |
|---|---|---|
| Brand Yellow / Black | #F8DA29 / #231F20 | **#FFDC00 / #171717** |
| 선택 상태 | 연노랑 배경 + 2px | **흰 배경 + 1px + 인디케이터** |
| 포커스 링 | 3px | **2px, offset 3px** |
| 카테고리 | 4×2 고정 | **한 줄 가로 스와이프** |
| 상품 목록 | 3열 + 페이지 이동 | **3열 세로 롱 스크롤 + 위·아래 버튼** |
| 상품 카드 | 투명 배경, Radius 0 | **연회색 타일, Radius 12** |
| 고대비·접근성 메뉴 | 제공 | **제공하지 않음** |

## 2. 공통 상태
| State | Background | Border (1px) | Text |
|---|---|---|---|
| Default | #FFFFFF | #949494 | #171717 / 500 |
| Selected (옵션) | #FFFFFF | #171717 | #171717 / 600 |
| Pressed | #F2F2F2 | #171717 | — |
| Disabled | #F5F5F5 | #D9D9D9 | #767676 |

- 모든 상태의 테두리는 1px이다. 상태가 바뀌어도 크기와 위치가 움직이지 않는다. 그림자는 없다.
- #949494는 흰 배경 대비 3.03:1이다(원안 #B8B8B8은 1.98:1이라 변경).
- #171717 테두리는 선택·눌림에만 쓴다. Secondary·삭제·아이콘 버튼, 키패드, 입력창의 기본 테두리도 #949494이다.
- 라디오: 미선택은 흰 원 + #171717 테두리, 선택은 #171717 원 + #FFDC00 점. 선택 여부를 색상만으로 표현하지 않는다.
- Focus Visible: #171717 2px, offset 3px. 키보드·보조 입력 전용이며 터치 후에는 남지 않는다.
- Radius: 버튼·옵션·탭 8px, 상품 타일·대화상자 12px, 배지 4px.

## 3. 버튼 위계
- Primary: #FFDC00 배경, #171717 글자, 테두리 없음, 700. 주문을 진행하는 행동에만 쓴다.
- 대화상자의 "닫기"는 Secondary이다.

## 4. 카테고리·하위 분류
- 카테고리 8개는 한 줄이며 옆으로 민다. 다섯 번째 탭이 반쯤 잘려 더 있음을 알린다. 선택한 탭은 화면 안으로 맞춘다.
- 선택: #FFDC00 채움 + #171717 글자(700). 체크 표시는 없다. 흰 글자는 대비 1.35:1이라 쓰지 않는다.
- HOT·ICE 필터는 없다. 하위 분류는 음료·푸드·상품에만 둔다.

## 5. 상품 목록
- 3열 세로 롱 스크롤. 분류를 바꾸면 맨 위에서 시작하고, 같은 분류에서는 위치를 유지한다.
- 우측 하단에 위·아래 버튼(80×80, 세로 배치). 한 번에 화면의 80%를 이동하고, 끝에서는 해당 버튼을 비활성화한다. 목록이 한 화면에 다 보이면 숨긴다.
- 카드: 연회색 이미지 타일 + 상품명(16px 아래, 최대 2줄) + 가격(8px 아래), 왼쪽 정렬. 행 간격 48px. 참고: 유아이볼의 더벤티 상품 목록.
- 카드에는 HOT·ICE 표기와 상세 정보 버튼을 두지 않는다. 누르면 바로 상품 화면으로 간다(지속 Selected 없음).
- 배지(썸네일 좌측 상단): 신메뉴(홈페이지 분류)는 NEW. BEST는 메뉴 데이터의 `best: true`에만 표시하며, 근거 없이 지정하지 않는다(현재 지정 없음). 배지가 있으면 사진을 아래로 내려 겹치지 않게 한다.

## 6. 상품 화면
- 이름·설명·가격 아래 "상세 정보 펼치기": 설명, 용량, 열량, 알레르기, 영양. 확인되지 않은 값은 채우지 않는다.
- 옵션 섹션 제목 아래에는 설명 문구를 두지 않는다.
- 온도: 아이콘 없이 "HOT 따뜻하게" / "ICE 차갑게". 두 가지면 라디오 선택(필수).
- 한 가지 온도만 되는 상품은 그 온도만 고정 안내 상자(버튼 아님)로 보여 주고, 제목 옆에 "HOT 전용" / "ICE 전용"을 붙인다. 비활성 버튼은 두지 않는다.

## 7. 접근성
- 접근성 버튼, 고대비 모드, 화면 확대는 팀 요청으로 뺐다. 언어 선택은 첫 화면에 남긴다.
- 기본 화면의 글자 크기, 대비, 터치 크기, 키보드 포커스는 유지한다.
- **PRD v3의 접근성 요구(FR-19)와 차이가 있으므로 팀 확인이 필요하다.**
