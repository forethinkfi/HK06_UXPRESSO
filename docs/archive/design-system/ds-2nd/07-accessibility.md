# 07. Accessibility Guidelines

초기 설계 가이드입니다. **무인정보단말기 접근성 관련 법령·표준(예: 한국형 웹 콘텐츠·무인정보단말기 접근성 지침 등) 충족 여부는 별도로 검토해야 하며, 이 문서만으로 준수를 주장하지 않습니다.**

## 터치 영역 — 물리 크기 환산

초기 검토 목표: 주요 터치 영역 **15~20mm**. 화면 px 크기는 패널의 물리 폭에 따라 달라지므로 환산식을 씁니다.

`px = mm × (가로 해상도 px ÷ 화면 물리 가로 mm)`

| 가정 패널 (16:9 세로 사용, **예시 가정**) | 물리 가로 | px/mm | 15mm | 20mm | 88px = |
|---|---|---|---|---|---|
| 21.5인치 | 약 268mm | 4.03 | 61px | 81px | 21.8mm |
| 32인치 | 약 398mm | 2.71 | 41px | 54px | 32.5mm |
| 43인치 | 약 535mm | 2.02 | 30px | 40px | 43.6mm |

→ 터치 영역 **88px**(일반 버튼 범위 안)은 위 가정들에서 모두 15mm 이상이지만, 실제 기기 규격은 [확인 필요]입니다. 21.5인치 이하라면 88px이 약 22mm이므로 여전히 충분하나 화면에 담을 수 있는 정보량이 줄어드는 점을 함께 검토합니다.

## Visual

- 일반 텍스트 4.5:1 이상, 큰 텍스트(24px 이상 굵게/28px 이상) 3:1 이상 — 02-foundations 계산표
- 충분한 글자 크기·행간, 핵심 정보(메뉴명·가격·옵션·금액)는 Body Large(28px) 이상 권장
- 색상에만 의존하지 않는 상태 표시: 선택 = ✓ + 테두리 + 문구, 오류 = 아이콘 + 문구, 성공 = ✓ + 문구
- 복잡한 배경 이미지 위 텍스트 금지(메뉴 이미지 위에 글자 얹지 않음)
- 노랑 면 위에는 검정 텍스트만, 노랑을 경계로 단독 사용하지 않음(흰 배경 1.36:1)
- 고대비 모드(High Contrast)를 Semantic 레이어 모드로 확장 검토

## Touch

- 주요 버튼 ≥ 96px(96~120), 일반 버튼 ≥ 72px(72~96), 아이콘 버튼 ≥ 64px — v1 기준. 가능하면 88px 이상 권장
- 인접 터치 요소 간격 ≥ 16px, 화면 가장자리 24px 이내에는 위험 행동(전체 취소 등)을 두지 않음
- 손 떨림·부정확한 터치 고려: 눌렀다 뗄 때 동작(touch-up), 터치 후 300ms 중복 입력 무시
- 드래그·핀치·길게 누르기 등 복잡한 제스처에 의존하지 않음. 가로 스크롤은 화살표 버튼 병행

## Cognitive

- 한 화면의 핵심 목적을 제목으로 명확히, 불필요한 선택지 최소화
- 필수/선택 구분(`꼭 골라요` / `선택 사항`), 현재 상태·다음 행동 안내(Progress + 화면 제목)
- 버튼 위치 일관(Primary 항상 하단 우측/전폭, `? 주문 도움` 항상 헤더 우측)
- 쉬운 용어, 선택 결과에 대한 즉각 피드백

## Language

- 기존 다국어 기능 유지, 언어 변경 시 주문 정보 유지
- 아이콘 + 텍스트 병기, HOT / ICE 등 관용 표현 유지
- 오류·결제 화면까지 같은 번역 적용, 언어별 길이 변화 대응(고정 폭 금지)

## Physical

- 다양한 신장·휠체어 이용자의 도달 범위 고려: 주요 조작 요소를 화면 하단 1/3~중앙에 두고 지나치게 높은 위치에 배치하지 않음
- 화면 높이 조절·낮은 위치 UI 모드 등 보조 기능 검토(실제 기기 지원 여부 [확인 필요])
- 카드 단말기·스캐너의 실제 위치를 고려해 화면 안내 방향 결정

## Time

- 불필요한 시간 제한 최소화, 장시간 미사용 시 연장 기회 제공(카운트다운 숫자 표시 없음)
- 결제 처리 중에는 세션 자동 초기화 제한
- 고객을 재촉하는 카운트다운·경고 사용 금지

## Screen reader / Focus (키오스크 음성 안내 기기 대비)

- 모든 인터랙티브 요소는 실제 버튼 요소 + 의미 있는 라벨, 아이콘 단독 버튼 금지
- 포커스 순서 = 시각 순서, Focused 상태는 3px 이상 링
- 상태 변화(담기, 오류, 승인)는 시각 변화와 함께 읽을 수 있는 상태 메시지로 제공(음성 안내는 P2)
