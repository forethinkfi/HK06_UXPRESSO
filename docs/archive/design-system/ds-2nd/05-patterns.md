# 05. Interaction Patterns

## 기본 주문 흐름

주문 시작 → 매장 이용 / 포장 선택 → 메뉴 탐색 → 메뉴·옵션 선택 → 장바구니 → 주문 확인 → 쿠폰 적용 및 결제 → 결제·주문 상태 확인 → 주문 완료

## 선택적 보조 흐름 (강제하지 않음)

쿠폰 사전 확인 · 취향별 메뉴 탐색 · 옵션 설명 · 결제 방법 안내 · 상황별 도움말 · 접근성 보조 기능. 일반 주문과 쉬운 주문을 **모드로 나누지 않습니다.** 모든 고객이 같은 화면에서 필요한 기능만 꺼내 씁니다.

## 패턴별 규칙

| 패턴 | 흐름 / 규칙 |
|---|---|
| 메뉴 탐색 | 카테고리(기본) + 취향 필터(선택) 병행. 필터 결과 0건이면 해제/대체 경로 제공. 하단 Cart Summary 고정 |
| 옵션 선택 | 필수(온도 등) 먼저, 선택 사항은 "안 골라도 돼요" 안내. 추가 금액은 선택 전에 표시, 총액 즉시 반영. 담기 버튼: `추가 옵션 없이 담기` ↔ `선택한 옵션으로 담기` |
| 주문 수정 (Edit) | 장바구니 → 수정할 메뉴 선택 → 옵션·수량 변경 → `변경 내용 저장` → 기존 장바구니로 복귀. 다른 메뉴 정보는 그대로 |
| 쿠폰 확인 | 시작 화면의 선택 기능 + 결제 단계 입력. 결과는 적용됨 / 사용 불가(사유 + 대체) / 확인 불가(직원). 쿠폰이 안 되어도 주문 유지 |
| 결제 | 수단 선택 → 행동 안내(카드 삽입/태그/스캔) → 처리 중 → 승인 / 거절 / 불확실. 처리 중 중복 요청 차단 |
| 오류 복구 | 오류 발생 → 상태·원인 안내 → 해결 방법 선택 → 주문 정보 유지 → 주문 재개 |
| 주문 도움 | 현재 단계 도움말 → 닫으면 기존 단계로 복귀 → 해결 안 되면 직원 도움 요청 |

## 세션 관리 (타이머 값은 [제안], 실제 운영 정책과 사용성 테스트로 확정)

| 상태 | 동작 |
|---|---|
| 주문 진행 중 | 주문 정보 유지. 화면 이동·도움말·언어 변경에도 보존 |
| 장시간 미사용 (미사용 120초, PRD v3 제안) | `아직 주문 중이신가요?` 대화상자. **이 대화상자에서만 실제 남은 시간**(60초 유예)을 표시. 계속 주문하기 / 주문 종료하기. 일반 화면에는 `2분 동안 조작이 없으면 종료 안내가 표시돼요.` + `시간 연장`만 낮은 위계로 표시 |
| 안내 후에도 응답 없음 (유예 60초) | **미결제 주문만** 초기화 |
| 결제 진행 중 | 자동 초기화 제한. 고객이 자리를 떠난 경우도 거래 상태 확인 우선 |
| 승인 여부 불확실 | 거래 상태 확인 우선, 재결제 유도 금지, 확인 불가 시 직원 안내 |
| 주문 완료 | 주문번호 확인 시간 제공 → 자동 초기화. 다음 고객에게 이전 주문이 보이지 않게 |

## Edge Cases — 설계에 반영할 상황

### Menu
품절 → Sold Out 라벨 + 선택 불가 · 메뉴 데이터 조회 실패 → 기본 데이터로 이어가기 · 필터 결과 없음 → 해제 안내 · 가격 변경 → 담은 뒤 변동 시 장바구니에서 알림 · 연속 터치 → 중복 담기 방지

### Options
필수 옵션 미선택 → 원인 + 해결 문구, 버튼은 유지 · 제공하지 않는 온도 → 비활성 + 이유 · 옵션 조합 제한 → 비활성 + 이유 · 최대 수량 → ＋ 비활성 + 안내 · 같은 메뉴 다른 옵션 → 별도 항목

### Cart
비어 있음 → 안내 + 메뉴로 이동 · 개별 삭제 · 전체 주문 취소(확인) · 여러 잔 중 일부 수정 · 매장/포장 변경 → 가격·옵션 영향 시 안내 · 주문 중 언어 변경 → 주문 유지

### Coupon
종류를 모름 → 종류별 안내 · 유효기간 만료 · 이미 사용 · 사용 불가 매장 · 적용 불가 메뉴 · 바코드 인식 실패 · 확인 서버 오류(쿠폰 없이 진행/직원) · **쿠폰 적용 후 주문 변경 → 재확인 후 결과 표시**

### Payment
카드 인식 실패(미요청 → 재인식) · 승인 실패(확정 → 재시도/다른 수단) · **승인 불확실(재결제 금지)** · 연속 터치(Loading + 요청 키로 중복 차단) · 결제 중 네트워크 오류(상태 확인) · 승인 후 주문 접수 실패(직원 안내, 결제 정보 보존)

### Session
주문 도중 이탈 → 미사용 확인 → 미결제 초기화 · 이전 고객 장바구니 잔존 → 완료·초기화 시 삭제 · 결제 중 이탈 → 거래 확인 우선 · 완료 화면 방치 → 자동 초기화 · 느린 사용자 → 자동 초기화 전 연장 기회

## 음성 주문 (PRD v3, 선택 기능 — 모의 입력)
- **한 흐름·공유 장바구니:** 터치↔음성 전환에도 장바구니·현재 화면 유지. 마이크는 사용자가 CTA를 누를 때만 켜지고 자동 재활성화하지 않음.
- **허용 범위:** 메뉴 탐색·추천·상품·온도·수량 선택·담기. **금지:** 최종 주문 확정, 쿠폰·적립, 전화번호, 결제 수단·승인. 결제 발화는 "직접 선택해야 해요" 안내만.
- **화면 우선:** 말씀하신 내용 → 안내 → 다음 행동을 항상 화면에 표시. 소리 없이도 완료 가능.
- **담기 전 확인:** 인식한 상품은 메뉴·온도·수량·금액을 보여 주고 확인 뒤에만 담음. 모호하면 후보 목록, 부족하면 온도 같은 필수 정보만 질문.
- **실패 복구:** "잘 듣지 못했어요" + 다시 말하기 / 화면에서 선택하기. 장바구니·화면 유지. 처리 중 도착한 이전 응답은 무효화.
- **전환:** 주문 확인 화면 진입 시 마이크 종료 + 인라인 안내(팝업 아님). 상태 정의는 [voice-cta-states.md](../../../design-system/voice-cta-states.md).

## 참고 시안 스타일 (PRD v3 레이아웃)
- **헤더:** 노랑 바에 홈 · 서비스명 · 언어 · 주문 도움. 메뉴 화면은 둘째 줄에 주문 방식(포장 주문/매장 식사, 바꾸기)과 검정 `음성으로 주문하기`.
- **메뉴:** 제목 "어떤 메뉴를 드시겠어요?" → 8개 대분류 4×2(선택 = 노랑 + 굵은 테두리 + ✓) → 하위 필터 알약 → 3열 카드 → "음성으로 메뉴 찾기" 박스. 데이터가 없는 분류는 빈 상태 안내.
- **하단 주문 바:** 미사용 종료 안내(2분) + 시간 연장 → 주문내역·합계 → 주문 취소 / 주문 확인(빈 장바구니면 비활성).
- **단계 표시:** 메뉴 선택 › 주문 확인 › 결제하기 (현재 단계 밑줄).
- **결제:** 금액 카드 → 혜택(멤버십·앱 쿠폰, 선택 사항) → 카드 결제(노랑 큰 버튼) → 휴대폰 결제 → 상품권 → 스탬프 → 하단 언어·접근성·도움말. 선택은 노랑/연노랑 + 굵은 테두리 + "✓ 선택됨".
- **음성 → 터치:** 음성 사용자에게만 "메뉴를 모두 담았어요!" + 주문 요약 + 직접 진행 안내. 처음부터 터치한 고객에게는 추가 안내 없음.
