## 화면 구성 (AS-IS)
| 화면 | 관찰 내용 |
|---|---|
| 메뉴 선택 | 노란 헤더 + 작은 진갈색 버튼(처음으로 / LANGUAGE). 카테고리는 헤더 안 텍스트 탭(신메뉴·추천메뉴·커피·디카페인·음료·티·푸드·상품). 메뉴는 4열 흰 카드(이미지·이름·주황 가격). HOT/ICE가 별도 메뉴로 나뉘어 스크롤이 김. 하단은 장바구니 표(메뉴·수량·가격) + 남은시간 카운트다운 + 주황 "전체삭제" 원형 버튼 + 진갈색 "결제하기" 영역(노란 금액) |
| 옵션 선택 | 노란 제목 바 + 닫기(✕) 원형 버튼. 메뉴 요약과 수량 스테퍼. 옵션 그룹마다 좌측 세로 노란 "선택옵션" 태그, 옵션 타일은 연한 크림 배경에 주황 글씨 가격. 빨간 "MGC 꿀팁" 태그. 하단 취소(진갈색) / 주문담기(주황) |
| 최종 확인 | 노란 제목 바 모달. 주문 내역 표, 빨간 경고("매장 이용 시 일회용컵 사용 불가"), 총 수량·총 금액, 뒤로(진갈색 ←) / 먹고가기(다회용컵·노랑) / 포장하기(일회용컵·주황) |
| 일회용품 선택 | 체크박스 3개(빨대·스틱 / 캐리어·봉투 / 직접 가져갈게요), 선택안함(회색) / 선택완료(주황) |
| 적립·결제 | 스탬프 적립 숫자패드(010-), 카드 결제(간편 결제) 모달: 총 결제금액·할부개월·카드번호, 취소(검정) / 승인요청(주황), 영수증 출력 여부 |

## 디자인 패턴 요약
| 항목 | AS-IS |
|---|---|
| Color | 노랑(헤더·제목 바) · 진갈색(보조 버튼·결제 영역) · 주황(주요 행동·가격) · 빨강(경고·꿀팁) · 크림(옵션 타일) · 흰 카드 |
| Typography | 산세리프, 카드 이름·가격이 작음(4열 구조) |
| Layout | 상단 헤더+탭 / 중앙 메뉴 그리드 / 하단 장바구니·결제 고정. 팝업(모달)이 많음 |
| Button | 주요 행동 = 주황, 취소·뒤로 = 진갈색, 닫기 = 원형 ✕ |
| Modal | 노란 제목 바 + 본문 + 하단 2버튼 |
| Option Selector | 그룹별 세로 태그 + 타일(선택 옵션 / 추천 옵션 구분) |
| Cart | 하단 고정 표 + 수량 ± 원형 버튼 + 전체삭제 |
| Feedback | 남은시간 카운트다운, 빨간 경고 문구 |

## 작성자가 짚은 장단점 (원문 요약)
- 장점: 할인·결제 옵션이 다양함. '메가 사이즈' 브랜드에 맞춰 이름에 '메가'를 드러내 크기 오해를 줄임(메가리카노 등).
- 아쉬움: 같은 음료를 HOT/ICE로 따로 나열해 스크롤이 길고 탐색이 오래 걸림. 계속 묻고 선택하는 팝업이 많아 뎁스가 불필요하게 깊음.

## TO-BE 반영 (유지 / 개선)
| 구분 | 내용 |
|---|---|
| 유지 | 노란 헤더 + 헤더 안 카테고리 탭, 진갈색 보조 컬러, 주황 주요 행동 버튼, 하단 고정 진갈색 결제 영역(노란 금액), 노란 모달 제목 바, 옵션 그룹 태그(선택 사항 / 꼭 골라요), 주황 계열 가격 색 |
| 개선 | HOT/ICE를 한 메뉴로 묶고 상세에서 온도 선택(스크롤·탐색 감소) |
| 개선 | 4열 소형 카드 → 2열 카드(이미지·이름·한 줄 설명·특징·가격)로 가독성·터치 영역 확대 |
| 개선 | 남은시간 카운트다운 제거(심리적 압박 완화), 경고 문구를 원인+해결 방법으로 재작성 |
| 개선 | 주황 글씨 가격은 대비 부족(흰 배경 약 2:1)이라 더 진한 주황(`#B34700`)으로 조정 |
| 개선 | 매장/포장을 첫 화면에서 동일 위계의 아이콘 버튼으로 선택(최종 확인 팝업의 노랑/주황 색 구분에 의존하지 않음) |
| 개선 | 팝업 단계 축소: 옵션은 한 시트에서 선택, 선택 사항 안내 문구 추가 |
