# AS-IS 키오스크 주문 플로우 — 정면 재구성

실제 메가커피 매장의 작은 키오스크(Easy Kiosk 단말 UI)를 촬영한 영상(약 3분 50초)에서 확인한 화면을 **정면 기준 768×1024로 다시 그린** 자료입니다. 영상은 손으로 찍어 화면이 기울고 손가락·반사가 가려서, 캡처본 대신 화면 내용을 읽어 다시 그렸습니다.

- `flow-board.png` — 28장을 플로우 순서대로 한 장에 모은 보드
- `screens/NN-이름.png` — 화면별 1536×2048 PNG (번호 = 플로우 순서)
- `index.html` — 같은 보드를 브라우저로 보기 / `screen.html?id=NN` — 화면 1장 / `screens.js`·`kiosk.css` — 소스

## 한계 (확인 필요)

- 색상·크기·간격은 영상에서 눈으로 읽은 **근사값**이며 공식 값이 아닙니다. 서체도 확인하지 못했습니다.
- 상품 이미지는 **일러스트로 대체**했고, 프로모션 이미지는 자리표시입니다.
- 읽을 수 없던 부분은 그대로 표시했습니다: 05·12번 일시품절 상품명, 09번 상품 설명, 18번 6/6 항목 제목, 23번 일부 결제수단명, 27번 팝업 상단 문구.
- 20번(주문 내역 확인)은 영상에서 아주 짧게만 보여 구성이 **추정**입니다.
- 영상의 휴대폰번호 등 **개인정보는 옮기지 않았습니다**(26번은 자리표시).
- 영상에서 14번째 화면(에스프레소 목록 재방문)처럼 같은 화면이 반복되는 구간은 한 장만 남겼습니다.
- 이 단말의 UI는 이전에 참고한 허들링클럽 자료의 노란색 키오스크와 **다른 기기·디자인**(파랑·흰색 계열)입니다.
