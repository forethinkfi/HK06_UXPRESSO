## 화면 구성 (화면에서 확인한 내용)

- **공통**: 상단 안내 문구, 노란 헤더(이전 · 화면 제목 · LANGUAGE), 카테고리 탭(추천메뉴 · 커피 · 음료 · 티 · 에이드 · 디저트 · MD), 4열 메뉴 격자, 하단(전체메뉴 · 쪽수 · 시간 · 진한 갈색 장바구니 바).
- **옵션 선택**: 수량 조절, 옵션 그룹별 선택(기본값은 노란색), `초기화`, `취소` / `선택완료`.
- **확인 팝업**: "입력하신 총 5,400원을 선택(주문) 해주세요." 아래에 선택한 수량, 추가한 가격, 선택한 상품 금액, 주문 전체 금액을 표시하고 `선택완료` 버튼 하나만 있습니다.
- **수량/수정**: 선택한 상품의 현재 수량·변경 수량·상품 금액·변경 금액을 보여주고, 숫자 키패드(`Clear`, `←`, `0` `00` `000`)로 수량을 바꿉니다. `종료` / `적용` 버튼이 있습니다.
- **적립번호 입력**: 어두운 팝업에 번호 입력칸과 숫자 키패드(`지우기`, `확인`), 닫기(X) 버튼이 있습니다. 제목은 "멤버십 번호를 입력해 주세요."입니다.
- **메뉴로 복귀**: 하단 장바구니 바가 주문내역(메뉴·수량·금액)으로 바뀌고 `주문 취소` / `주문하기` 버튼이 나타납니다.

## 확인이 필요한 부분

화면을 옮겨 정리하는 과정의 실수일 수 있어서, 영상과 대조해 확인해 주세요.

- 03번 화면 이전 버튼 글자가 "어전"으로 보입니다 (02번, 05번은 "이전").
- 시간 표시 문구가 화면마다 다릅니다: 01번 "현재시간 120분", 02~05번·08번 "한정시간 120초", 06번 "남은시간 120초".
- 05번 팝업은 선택한 상품 금액 3,300원, 수량 2, 주문 전체 금액 5,400원으로 계산이 맞지 않습니다 (06번·08번은 3,300원 × 2 = 6,600원으로 맞습니다).
- 같은 메뉴의 가격이 화면마다 다릅니다 (예: 바닐라라떼 01번 3,500원, 02번 3,200원, 03번 2,800원. ICED카페라떼 메뉴판 2,500원, 옵션·수량·주문내역에서는 3,300원).
- 06번 수량 수정 팝업 아래에 "아래 이미지를 휴대폰에 저장하고 매장에서 사용해 주세요." 문구와 마이쿠폰 바코드 이미지가 있습니다. 수량 변경과 관련 없는 내용이라 실제 화면에 있었는지 확인이 필요합니다.
- 07번 화면의 제목은 "적립번호 입력"인데 팝업 문구는 "멤버십 번호를 입력해 주세요."로 서로 다릅니다.
