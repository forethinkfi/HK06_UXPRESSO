# UXPRESSO — Kiosk UI Kit

> **2차 버전이 [`docs/design-system/`](design-system/README.md)에 있습니다.** 이 문서는 키오스크 화면 기준 1차 버전이며 현재 프로토타입(`public/`)이 사용합니다.

메가MGC커피의 공식 디자인 시스템이 아닌, 기존 화면 관찰을 바탕으로 만든 **비공식 개선 디자인 시스템**입니다. 브랜드 정체성(노랑·검정·흰색)을 유지합니다. 컴포넌트 데모: `/kit.html`

## Foundations
실제 키오스크 화면 분석([as-is-analysis.md](as-is-analysis.md))에서 읽은 패턴(노란 헤더·제목 바, 진갈색 보조 컬러, 주황 주요 행동)을 유지하고, 대비가 부족한 부분만 조정했습니다. 색상 값은 화면에서 추정한 근사값이며 공식 값이 아닙니다.

| 토큰 | 값 | 용도 |
|---|---|---|
| Yellow | `#FFD400` | 헤더·카테고리 탭 바, 모달 제목 바, 옵션 그룹 태그 |
| Dark brown (Ink) | `#33190A` | 텍스트, 선택 상태, 하단 고정 결제 영역, 주문 방식 바 |
| Orange | `#FF9F1A` | Primary 버튼 (현재 단계의 핵심 행동) |
| Orange ink | `#B34700` | 가격 텍스트 (흰 배경 대비 약 5.5:1) |
| Cream | `#FFF8DC` | 옵션 타일, 안내 박스 |
| Soft yellow | `#FFF4C2` | 눌림·보조 강조 |
| Mute | `#5B4A3F` | 보조 텍스트 |
| Background | `#FAF8F2` | 화면 배경 |
| Success / Error | `#17692F` / `#B3261E` | 결과 표시 (색상 + 아이콘 + 문구 병행) |
| Radius | 28px | 버튼·카드 |
| Stage | 1080 × 1920px | 임시 해상도 (실기기 확정 전) |

타이포그래피는 시스템 한글 폰트(Apple SD Gothic Neo, Pretendard, Noto Sans KR), 본문 32px, 제목 44~56px, 가격·금액은 굵게.

## 버튼 (6종 × 4상태)
| 컴포넌트 | 용도 | 클래스 |
|---|---|---|
| Primary | 현재 단계의 핵심 행동 (주황) | `.btn.pri` |
| Secondary | 메뉴 더 담기, 수정 등 보조 행동 | `.btn.sec` |
| Selection | 매장·포장, 온도, 옵션, 결제 수단 | `.choice` `.mode` `.method` |
| Navigation | 이전 화면, 메뉴로 이동 | `.back` |
| Help | 주문 도움 | `.helpbtn` |
| Destructive | 전체 주문 취소 | `.btn.dng` |

상태: Default · Pressed · Selected(`aria-pressed="true"`) · Disabled. 동등한 선택지는 같은 크기·위계로 두고, 선택은 **색상 + ✓ + 테두리**로 구분합니다.

## 접근성 기준
- 터치 영역 최소 88px, 요소 간 충분한 간격
- 일반 텍스트 명도 대비 4.5:1 이상을 목표(전체 측정은 미완료)
- 색상만으로 선택·오류를 전달하지 않음
- 애니메이션·그라데이션 최소화, `prefers-reduced-motion` 고려
- 주요 조작 요소는 접근 가능한 높이에 배치(실제 설치 높이 확인 후 확정)

## UX Writing
| 지양 | 사용 |
|---|---|
| 먹고 가기 / 픽업하기 | 매장에서 먹기 / 포장하기 |
| HOT / ICE | 따뜻하게 (HOT) / 차갑게 (ICE) |
| 논커피 | 커피가 들어가지 않은 음료 |
| 다음 | 주문 내역 확인 |
| 담기 | 장바구니에 담기 |
| 확인 | 변경 내용 저장 |
| 취소 | 옵션 선택 취소 |
| 초기화 | 전체 주문 취소 |
| 결제 | 4,500원 결제하기 |

오류 메시지는 **원인 + 해결 방법**을 함께, 재촉하거나 실수를 지적하지 않는 어투로 씁니다.
