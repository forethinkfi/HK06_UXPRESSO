# UXPRESSO PRD v3.0 요약과 구현 매핑

PRD v3.0(Voice-Driven & Inclusive UX)을 읽고 정리한 요약입니다. **원문 전체는 이 저장소에 보관하지 않았습니다**(요청 시 `docs/prd-v3.md`로 추가). 기준 디자인 시스템은 [Kiosk Design System v1.0](design-system/uxpresso-kiosk-design-system-v1.md)입니다. 비공식 프로젝트이며 모든 효과는 검증 전 가설입니다.

## v2.0 → v3.0 핵심 변화
- 터치와 음성이 **하나의 주문 흐름·공유 장바구니**를 쓴다 (One Flow, Multiple Ways).
- 음성은 메뉴 선택까지만 지원 — **최종 주문 확인·혜택·적립·결제는 직접 터치** (Speak to Select, Touch to Confirm).
- AI 안내는 모두 화면에 표시하고, 음성 없이도 전체 주문이 가능해야 한다.
- 세션: 미사용 120초 → 종료 안내 → 60초 유예 → 초기화(제안). 결제 중에는 초기화하지 않는다.
- 일반 상태 시간 안내는 낮은 위계(중립 문구 + 시간 연장). 종료 안내에서만 실제 남은 시간 표시.
- 음성 상태 9종: idle · listening · processing · responding · awaiting_input · confirming · success · error · ended.

## 의도적으로 한 선택·한계
- **실제 음성 인식 없음.** Speech-to-Text 대신 "모의 입력" 문장을 눌러 말한 것처럼 입력합니다(PRD 15.3 허용). 문구에 연습용임을 표시했습니다.
- **오디오 출력 없음.** 모든 안내가 화면에 표시되어 음성 켜기/끄기·다시 듣기는 의미가 없어 넣지 않았습니다(P1).
- 추천은 데이터의 `featured`(주요 메뉴) 기준이며 인기·BEST를 표시하지 않습니다. 디카페인은 테스트 메뉴 1개(`decaf`, 가격·설명 예시)를 추가했습니다.
- 신메뉴·푸드 요청은 데이터가 없다고 안내합니다(임의 생성 금지).
- 120/60초는 PRD의 프로토타입 제안값이며 현장 타이머 확인 후 확정합니다.
- 사용성 테스트·분석 이벤트(24장)는 미구현입니다.
