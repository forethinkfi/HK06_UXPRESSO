# 결제·제휴 브랜드 로고 자리

각 브랜드의 **공식 로고 파일**만 넣습니다. 직접 그리거나 비슷하게 만들지 않고, 색과 비율을 바꾸지 않습니다. 각 브랜드의 사용 조건을 확인하세요. 이 저장소는 공개 상태입니다.

1. 파일을 이 폴더에 `아이디.svg`(또는 png)로 넣습니다. 가로 160 × 세로 40px 안에서 보입니다.
2. `data/payments.json`의 같은 항목에 `"logo": "logos/아이디.svg"`를 추가합니다.

## 공식 사이트 확인 결과 (2026-11-26, 일부만 확인)
지금까지 이 비공식 시안에 바로 써도 되는 로고 파일은 찾지 못해, 아무것도 내려받지 않았다.

| 브랜드 | 확인한 내용 |
|---|---|
| 알리페이 | 정식 계약된 가맹점·파트너만 사용 가능 (https://docs.alipayplus.com/alipayplus/legal/docs/trademark_merchant) |
| 네이버페이 | 공개 자료는 네이버 회사 로고뿐 (https://www.navercorp.com/company/brandGuide). Npay 디자인 페이지(developers.pay.naver.com)는 이 도구에서 열 수 없어 미확인 |
| 카카오페이 | 가맹점 신청 후 파트너 안내로 제공하는 것으로 보임 (https://partner.kakaopay.com/partner/online/guide/payment-method) |
| BC 페이북 | CI 소개 페이지에서 페이북 파일은 찾지 못함 |
| CJ ONE | 뉴스룸 이미지는 보도용이며 상업적 이용 불가라고 안내 |
| 그 밖 | 검색에서 공개 내려받기 페이지를 찾지 못함 |
